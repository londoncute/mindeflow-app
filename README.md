# mindeflow-app

Текущая версия приложения использует:

- текущий фронтенд из `frontend/`
- текущий Go backend из `backend/`
- PostgreSQL в Docker

Фронтенд раздается самим backend, поэтому после запуска все открывается по одному адресу:

- `http://localhost:8080`

API живет под префиксом:

- `http://localhost:8080/api/v1`

## Что уже собрано

В приложении закрыты основные задачи из backlog:

- вход и регистрация
- изоляция данных по пользователям
- inbox с формой добавления
- обработка inbox в задачу внутри существующего проекта
- создание проекта прямо из inbox
- `Скип` для отправки элемента в конец очереди
- удаление `Удалить` с 2-секундным таймером
- создание и редактирование проектов
- материалы проекта
- создание задач внутри проекта
- удаление проекта
- перестановка задачи в начало очереди проекта
- запуск и завершение задачи с 2-секундным прогрессом
- удаление одной задачи и удаление всех задач проекта
- мгновенные обновления интерфейса без перезагрузки страницы
- сворачиваемое левое меню
- кнопка выхода перенесена в левое меню

Дополнительно добавлены два режима работы:

- `Обезьяна`
  - видит только задачи
  - работает только с одной текущей задачей за раз
  - имеет кнопку `Следующая задача`
  - не дает перейти в `Умный тип`, пока очередь задач не пуста, если не удерживать подтверждение 5 секунд
- `Умный тип`
  - видит `Inbox` и `Projects`
  - не может выполнять задачи
  - редактирует только один проект за раз
  - имеет кнопку `Следующий проект`
  - отправляет в режим `Обезьяны` первые задачи из каждого проекта
  - не дает перейти в `Обезьяну`, если есть проекты без задач, если не удерживать подтверждение 5 секунд

## Что нужно установить

- Go
- Docker Desktop

Важно:

- Docker Desktop должен быть запущен до `docker compose up -d`
- отдельный инструмент миграций не нужен, backend сам применяет SQL-файлы из `backend/migrations` при старте

## Как запустить

1. Перейдите в папку backend:

```powershell
cd .\backend
```

2. Убедитесь, что Docker Desktop запущен.

3. Поднимите PostgreSQL:

```powershell
docker compose up -d
```

4. Запустите backend:

```powershell
go run .\cmd\app\main.go
```

5. Откройте приложение:

```text
http://localhost:8080
```

## Тестовый вход

- email: `user@example.com`
- пароль: `mindflow123`

Эти данные уже показаны и на экране логина.

## Регистрация

На экране входа теперь доступны два режима:

- `Войти`
- `Регистрация`

При регистрации можно создать новый аккаунт по имени, email и паролю. После успешной регистрации пользователь автоматически входит в приложение.

## Как собрать exe

Из папки `backend`:

```powershell
go build -o mindflow.exe .\cmd\app\main.go
```

Запуск:

```powershell
.\mindflow.exe
```
