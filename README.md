# 🧠 MindFlow — Система личной продуктивности

Короче, это таск-менеджер по «Джедайским техникам». Если ты задолбался держать всё в голове и хочешь, чтобы входящие задачи сами раскладывались по полочкам — ты по адресу.

## 🚀 Как запустить эту дичь (Fast Track)

Не надо ничего настраивать руками, если у тебя есть **Docker**. Это самый ленивый и правильный способ.

### Шаг 1: Клонируем репозиторий
```bash
git clone https://github.com/londoncute/mindeflow-app.git
cd mindeflow-app
git checkout demo
```

### Шаг 2: Запускаем через Docker
Убедись, что Docker Desktop запущен, и просто пиши в терминале:
```bash
docker-compose up --build -d
```
*Эта команда сама скачает Go, соберет базу и поднимет фронтенд.*

### Шаг 3: Проверяем
* **Фронтенд:** Открывай в браузере `http://localhost:80` (или просто `index.html` через Live Server).
* **Бэкенд (API):** Живет на `http://localhost:8080/api/v1/user`.

---

## 🛠 Если Docker бесит (Запуск руками)

Если ты олдскул и хочешь всё делать сам:

### 1. Бэкенд (Go)
Тебе нужен установленный Go 1.21+.
```bash
cd backend
go mod tidy
go run main.go
```
*Сервер поднимется на порту 8080.*

### 2. Фронтенд (JS/Tailwind)
Тут вообще всё просто. Заходи в папку `frontend` и открывай `index.html` в любом браузере. 
> **Важно:** Мы используем CDN для Tailwind и FontAwesome, так что интернет должен быть включен.

## 📦 Структура проекта
* `/backend` — Сердце системы на Go (API, работа с задачами).
* `/frontend` — Красивая морда на Tailwind CSS и чистом JS.
* `docker-compose.yml` — Магия, которая склеивает всё это вместе.

## ⚠️ Возможные косяки
1.  **Порт 8080 занят:** Убей процесс, который его держит, или поменяй порт в `main.go`.
2.  **CORS:** Если фронт не видит бэк, проверь настройки CORS в `main.go` (там должен быть разрешен `*` или твой домен).
3.  **Кодировка:** Все файлы строго в **UTF-8**, иначе вместо букв увидишь боль и страдание.

**Развлекайся. Сделано с душой и матами.**
